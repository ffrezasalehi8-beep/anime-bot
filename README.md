# 🤖 Telegram Anime & Manga Bot

یک ربات تلگرامی نوشته‌شده با پایتون برای جستجو و دریافت اطلاعات کامل انیمه‌ها، مانگاها و شخصیت‌ها با استفاده از API رایگان **Kitsu API**. این ربات به‌صورت کامل async نوشته شده و برای میزبانی روی پلتفرم **Railway** بهینه‌سازی شده است.

---

## ✨ قابلیت‌ها

- 🎬 **جستجوی انیمه:** دریافت پوستر، امتیاز، تعداد قسمت‌ها، وضعیت پخش و خلاصه داستان
- 📖 **جستجوی مانگا:** نمایش پوستر، تعداد چپترها، جلدها و امتیاز
- 👤 **جستجوی شخصیت‌ها:** دریافت تصویر و توضیحات مربوط به شخصیت
- 💡 **پیشنهاد هوشمند:** پیشنهاد ۱۰ انیمه مشابه بر اساس دسته‌بندی و ژانر
- 🏆 **انیمه‌های برتر:** لیست ۱۰ انیمه برتر تاریخ
- 🍂 **انیمه‌های فصل:** لیست انیمه‌های در حال پخش و محبوب
- 🛡 **ضد خطا:** مدیریت کامل استثناها و جلوگیری از خطاهای `NoneType` و `HTML Parsing`

---

## 🛠 پیش‌نیازها و پیش‌فرض‌ها

- **Python 3.10+** (تست شده روی Python 3.13)
- **python-telegram-bot v22.3**
- **httpx** (برای درخواست‌های Async)

---

## 🚀 راه اندازی و نصب روی Railway

1. این مخزن را در اکانت گیت‌هاب خود Fork یا Clone کنید.
2. وارد پنل **[Railway.app](https://railway.app)** شوید و یک پروژه جدید ایجاد کنید.
3. مخزن گیت‌هاب خود را به Railway متصل کنید.
4. در بخش **Variables** پروژه، متغیر محیطی زیر را تنظیم کنید:

   - **Key:** `BOT_TOKEN`
   - **Value:** `توکن دریافت شده از BotFather`

5. پروژه به‌صورت خودکار دپلوی و اجرا می‌شود.

## 📱 دستورات ربات

| دستور | توضیح | مثال |
| :--- | :--- | :--- |
| `/start` | شروع کار با ربات و مشاهده راهنما | `/start` |
| `/anime` | جستجوی اطلاعات یک انیمه | `/anime Naruto` |
| `/manga` | جستجوی اطلاعات یک مانگا | `/manga Berserk` |
| `/character` | جستجوی اطلاعات یک شخصیت | `/character Naruto` |
| `/recommend` | دریافت ۱۰ انیمه پیشنهادی مشابه | `/recommend Naruto` |
| `/top` | دریافت ۱۰ انیمه برتر تاریخ | `/top` |
| `/season` | لیست انیمه‌های محبوب در حال پخش | `/season` |
